## 執行方式

建議使用 Google Colab 開啟作業 Notebook，並由 Notebook 內的安裝與授權步驟設定需要的套件、Google Sheets 存取權及 Gemini API。需要 API 金鑰的作業請透過 Colab Secrets 設定，不要把金鑰寫入或提交到 Notebook。

部分作業會讀寫 Google Sheets，執行前請確認目前 Google 帳號有對應試算表的存取權。Notebook 已保留原有程式碼及執行結果。
